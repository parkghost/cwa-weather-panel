電子紙天氣面板

一塊 4.2 吋黑・白・紅三色電子紙，常駐顯示中央氣象署的鄉鎮天氣預報。每 3 小時抓一次資料，其餘時間不發光、不耗電，安靜得像牆上的一張紙。

Overview

產品介紹

這是一台以 ESPHome 打造的壁掛／桌上型天氣面板：每 3 小時抓取中央氣象署「鄉鎮天氣預報」開放資料，上半部顯示今天的日期、天氣圖示、溫度範圍、降雨機率與天氣描述，下半部可在「未來 18 小時（逐 3 小時）」與「未來 7 天」兩種預報之間切換。雨天與雷雨等需要留意的天氣，會以紅色墨水標示。

Quick Start

快速設定

機器已預載韌體。接上電源後，五個步驟完成設定：

  1. 接上電源
    使用 USB 5V 充電器與 Type-C 充電線連接面板。
  2. 連上家中 WIFI
    用手機連線設備的 WIFI AP（SSID CWA Weather Panel，密碼 12345678）， 打開 http://192.168.4.1/，選擇家中 2.4GHz WIFI 並輸入密碼。

    若是透過本頁「安裝韌體」由瀏覽器燒錄，安裝完成後可依提示直接設定 WIFI，跳過此步驟。

  3. 進入設備網頁
    設定完成前，螢幕會顯示「需要設定」畫面與設備網址（http://設備IP/），用瀏覽器開啟即可。
  4. 申請並填入 API 金鑰
    於氣象資料開放平臺免費註冊、取得 API 授權碼，填入 Forecast - API Key。
  5. 設定天氣地點
    Forecast - City Name 選縣市（例：新北市）， Forecast - Town Name 填鄉鎮（例：中和區）， 名稱以鄉鎮對照表為準。 完成後畫面即自動更新為天氣預報。

Daily Use

日常使用

預報模式

  • Forecast - Mode — 切換 18-Hour Forecast（未來 18 小時，每 3 小時一欄）與 7-Day Forecast（未來一週）

資料更新

  • 每 3 小時整點自動抓取預報並重繪畫面
  • 手動更新：Forecast - Update All
  • 更新狀態：3D/7D Last Updated、Last Success、Last Error
  • 電子紙僅在資料更新時重繪；每 10 次局部更新會做一次全螢幕更新以清除殘影

韌體更新

  • 自動偵測：定時檢查，Firmware 顯示目前狀態
  • 手動偵測：Firmware - Check
  • 自動更新：Firmware - Auto Update（預設開啟）偵測到新版即自動安裝，期間螢幕顯示「韌體更新中」，請勿關閉電源
  • 手動更新：關閉自動更新後，以 Firmware - Perform Update 執行

排程重啟

  • Schedule Reboot - Enabled 搭配 Schedule Reboot - Time（預設 05:00）

Install & Build

安裝與編譯

使用瀏覽器 USB 安裝

  1. 使用數據線連接設備 USB 與電腦
  2. 按下方按鈕，選擇設備連接埠（COMx），依提示安裝 — 安裝過程請勿離開頁面
此瀏覽器不支援 Web Serial，請改用桌面版 Chrome 或 Edge 此頁面需透過 HTTPS 開啟才能安裝

安裝時可選擇是否清除既有設定（Erase device）；安裝完成後可直接於瀏覽器設定 WIFI。

使用設備網頁 OTA 安裝

  1. 下載 cwa-weather-panel-esp32s3.ota.bin
  2. 進入設備網頁的 OTA Update，選擇檔案後按 Update

自行編譯

  1. 安裝 ESPHome CLI
  2. 取得原始碼： 
    git clone https://github.com/parkghost/cwa-weather-panel.git
cd cwa-weather-panel
  3. 編譯與安裝，下列方式擇一：
    • USB：esphome run cwa-weather-panel-esp32-s3.factory.yaml --device COMx
    • OTA：esphome run cwa-weather-panel-esp32-s3.factory.yaml --device 設備IP
    • 僅編譯：esphome compile cwa-weather-panel-esp32-s3.factory.yaml

Troubleshooting

疑難排解

螢幕顯示「需要設定」

表示 API 金鑰或地點尚未填寫。畫面會列出缺漏項目與設備網址，開啟網址補齊 Forecast - API Key、Forecast - City Name、Forecast - Town Name 後自動恢復。

畫面一直沒有資料

  • 確認 Forecast - API Key 為有效金鑰
  • 確認地點名稱與官方一致：見鄉鎮對照表（例：臺北市，不是台北市）
  • 查看 3D/7D Last Error 與設備網頁右側日誌

查看設備日誌

  • Web Console：進入設備網頁，右側即時資訊
  • ESPHome CLI：esphome logs cwa-weather-panel-esp32-s3.yaml --device 設備IP
  • ESP Web Tool：Connect > 選擇連接埠 > LOGS

回復原廠設定

進入設備網頁，按 Factory Reset — 會清除 WIFI 與所有設定，回到「需要設定」狀態。
